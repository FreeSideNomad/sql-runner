## Project Overview

**SQL Runner** is a Spring Boot 3.5.9 web application for managing and executing SQL queries with features like:
- Query management (SELECT and UPDATE_WORKFLOW types)
- Multiple database connections (SQL Server, PostgreSQL, DB2)
- UPDATE workflow with preview, execute, backup, and rollback
- Execution history and audit logging
- CSV export with RFC 4180 compliance

## Key Features Implemented

### 1. F008-S011 Enhanced UPDATE Parameter Binding
Three UPDATE binding modes for UPDATE_WORKFLOW queries:
- **STANDARD**: User parameters only (existing behavior)
- **BATCH**: Single UPDATE with `:id_list` collecting all preview primary keys
- **ROW_BY_ROW**: Per-row UPDATE using SELECT column values as parameters

**Key Files**:
- `src/main/java/com/ivamare/domain/UpdateBindingMode.java` - Enum
- `src/main/java/com/ivamare/service/UpdateParameterAnalyzer.java` - Detects binding mode, extracts parameters
- `src/main/java/com/ivamare/service/QueryConfigValidator.java` - Edit-time validation
- `src/main/java/com/ivamare/service/UpdateWorkflowService.java` - Mode-specific execution

### 2. CsvUtils - RFC 4180 Compliant CSV Generation
- `src/main/java/com/ivamare/util/CsvUtils.java`
- Properly quotes fields with commas, quotes, newlines
- Escapes double quotes by doubling (`"` → `""`)
- UTF-8 BOM for Excel compatibility
- Used by all controllers that export CSV

### 3. History Detail Page Enhancements
- `src/main/resources/templates/history/detail.html`
- Download backup data as CSV
- Download rollback script
- Execute rollback directly from history page
- Shows rollback status and metadata

### 4. Validation for UPDATE_WORKFLOW
Required fields when saving UPDATE_WORKFLOW queries:
- `primaryKeyColumn` - identifies rows for backup/rollback
- `rollbackColumns` - columns to restore during rollback

## Known Issues / Quirks

1. **CodeMirror CSS**: Must be inside `th:fragment="content"` div or it won't be included in rendered page (Thymeleaf layout issue)

2. **YAML Parsing**: `updateBindingMode` must be explicitly parsed in `QueryExecutionService.parseConfig()` - was a bug fixed in this session

3. **Pre-commit/Pre-push Hooks**: Project has git hooks that run tests and formatting checks. Commits may take time due to full test suite.
